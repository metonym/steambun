# hello

The smallest steambun app: `package.json`, `index.html` and `main.ts`.
No config, no core, no Swift. The name, Hello, comes from `package.json`.

```sh
bun dev   # a browser tab with hot reload
bun app   # build and open build/Hello.app
```

The .app is the Swift shell and the page, about 1 MB.
Next: `native-op` adds Swift, `core` adds Bun.
